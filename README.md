# ProcrastiNoT 
--------
![[Pasted image 20261012040526.png]]

ProcrastiNoT is a RaspberryPi Operated project : basically a 2 part system, Table Deck and watch, aimed at helping high school students managing thier time efficiently.
## What it is
------

ProcarstiNoT is simply a two devices ,Table Dock and Custom Watch, built system to monitor the Student Performance Across the day through tracking the following : 
1. The Student Presence Time on Studying Table
2. The Actual Tabs opened on Laptop {Closing Prohibited Tabs on Studying Times}
3. The Student Actual Focus Time {Through DL Model that count actual time where student were focusing on Laptop}
and Keep Student Aware using the Custom Watch When he bypass Breaks Time, With sensible punishment through Vibration motor to force student returning to his studying place.
## Why?
-------

The project is actually created to satisfy as a solution to two main problems :
1. High School Students That lose a lot of untrack times through Procrastination and Long Breaks
2. Parents Needs to monitor their children Performance and actual studying time daily
